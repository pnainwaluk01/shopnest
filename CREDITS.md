# Image & Icon Credits

All images and icons in this project are downloaded and stored locally under
`images/` and `assets/icons/` — nothing is loaded from an external URL at runtime.
This file records where each asset came from so attribution requirements (where
applicable) are met.

## Icons

Sourced from two open icon sets, downloaded once and stored as individual
files under `assets/icons/` (one SVG per icon, e.g. `cart.svg`, `heart.svg`),
each holding a single `<symbol id="icon">` referenced via `<use href="assets/icons/NAME.svg#icon">`:

- **Lucide** — ISC License. https://lucide.dev
- **Simple Icons** (brand/social logos: Facebook, X/Twitter, Instagram, YouTube) — CC0 1.0. https://simpleicons.org
